# Historical completion costs and outcome-basis audit

This extension accompanies Sections 3.8 and 4.8, Table 5 and Appendix D. It is an exploratory document audit of all 31 positive-finance matched projects classified closed in the FY25 IBRD annex: 27 closed in both annexes and four transitions. The earlier results were known before this extension; DESIGN.txt is an internal sequential analysis record, not a public preregistration.

## Reproduction

From the package root, first install the pinned requirements and regenerate the original IBRD inputs using ibrd/README.md. In particular, ibrd/data/project_records.csv is generated by ibrd/extract_ibrd.py and is not redistributed. Then run:

```
python -m pip install -r ibrd_deep/requirements.txt
python ibrd_deep/acquire_sources.py
python ibrd_deep/build_audit.py
python ibrd_deep/analyze_cost.py
python ibrd_deep/rounding_bounds.py
python ibrd_deep/validate_cost_audit.py
```

The acquisition script downloads official documents directly and requires their exact SHA256 hashes. A changed download is a source-vintage discrepancy, not permission to overwrite the expected identity. It can also verify already downloaded files. No source PDFs or full extracted text are included. Python 3.12.14 with the pinned project environment was used. Scripts resolve paths relative to their own folder.

## Inputs and adjudication

all_sources.json is the 60-file inventory and supplementary source bibliography: document identifiers, titles, dates, report numbers, official URLs, PDF-page counts, byte sizes and hashes. source_manifest.json contains 28 IEG reviews, icr_manifest.json 31 ICR files, and isr_manifest.json one interim report. Separately catalogued copies of a joint corridor report are retained. Sixty files are not sixty independent confirmations. Completion material covers 30 projects; P132741 is traced only to a 2023 ISR.

audit_universe.csv is a minimal 31-project audit index, not the complete source table. build_audit.py records manually adjudicated field values, page positions, numeric tokens, outcome-horizon classifications and cost-boundary exclusions. It creates audit_ledger.json and results/audit_ledger.csv. Page references are PDF page positions, not printed labels. Manual scope interpretations remain reviewable judgments; tests do not prove them. Source amounts are retained, not silently corrected.

## Interpretation and main results

Twenty-two projects have acceptable direct historical whole-project/program USD costs. Ten also have an explicit annual outcome basis and source-concordant value (strict cohort). Fifteen include three documented lifetime averages and two component reconstructions, kept separate from the strict cohort. The same historical completion cost is used in both report vintages: this is a controlled reference denominator, not two observed annual cost histories. Historical nominal USD costs are not deflated to a common price year and do not support real-efficiency rankings across projects or banks. Source dates in the strict cohort are on or before June 30, 2024; historical public availability is not reconstructed.

The strict change is +0.015963%, with allocation-display-rounding bounds -0.006134% to +0.038065%, spanning zero. The expanded change is -0.207916%, with bounds -0.227952% to -0.187876%; its sign reverses for some project/country omissions. Fixed-weight changes are mechanically zero because both GHG inputs and the cost reference are unchanged. They do not establish physical stability. The 22-project cost-only result retains unresolved numerators and is only a reporting diagnostic.

Jointly excluding seven unit/horizon/basis flags from the original 65-project reporting comparison changes -2.484119% to +0.016053% over 58 projects. This weakens the original directional interpretation. The 38 active projects were not completion-audited; the 58 are not all independently verified. Completion-document agreement is not validation of a physical counterfactual.

## Outputs

- audit_ledger.csv: all inclusions/exclusions and source locators.
- cost_results.csv, cost_summary.json: cohorts, levels, changes and coverage.
- cost_decomposition.csv: project contributions and exact bridges.
- cost_leave_one_out.csv: project/country omissions.
- allocation_rounding_bounds.csv: allocation-only precision bounds, not confidence intervals.
- flag_exclusion_sensitivity.csv: joint measurement-flag exclusion.
- deep_validation.json: 307 passed checks, including 53 independently parsed cost/outcome field locators, source hashes, semantic anchors, Decimal arithmetic and exhaustive corner checks of rounding bounds.

The original package's historical outcome_trace.csv predates the ISR discovery. For P132741, the current audit_ledger.csv and manuscript Appendix C supersede the earlier unresolved trace. Other original results remain unchanged.
